# Участие

Проект маленький, поэтому правила короткие.

## Сборка и запуск

Нужен Godot 4.7. Движок в репозиторий не входит.

```bash
mkdir -p .tools
cp /path/to/Godot_v4.7-stable_linux.x86_64 .tools/godot
chmod +x .tools/godot
.tools/godot --path .
```

## Тесты

```bash
tests/run_all.sh
```

Скрипт импортирует ресурсы и прогоняет юнит-проверки, регрессию сюжета,
свет/шум и подвал. PR без зелёных тестов не мержится.

## Pull request

- Одна задача — одна ветка и один логический коммит.
- Сообщения — [Conventional Commits](https://www.conventionalcommits.org/ru/):
  `feat`, `fix`, `docs`, `refactor`, `test`, `ci`, `chore`.
- В описании: что меняется, зачем и как проверено.
- Скриншоты или запись — если менялся интерфейс.
- `VERSION` и `CHANGELOG.md` не трогайте без обсуждения: версию поднимает
  мейнтейнер при выпуске.

## Ассеты

Текстуры и звук генерируются скриптами из `tools/`. Не правьте PNG и WAV
вручную: изменения потеряются при следующей генерации. Меняйте генератор
и пересобирайте партию.

## Стиль

- GDScript: табы, `snake_case`, типизированные переменные где возможно.
- Комментарии — по делу, на русском или английском, но в одном файле.
- Не добавляйте сторонние ассеты и зависимости без обсуждения.
